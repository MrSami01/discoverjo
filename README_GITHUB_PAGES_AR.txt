أثرنا — نسخة GitHub Pages لمستودع discoverjo

سبب الشاشة البيضاء في الرابط السابق:
كان index.html يطلب ملفات JavaScript وCSS من /assets على جذر النطاق، بينما موقع GitHub Pages موجود تحت /discoverjo. هذه النسخة مبنية للمسار الصحيح /discoverjo/ وتحتوي أيضاً على 404.html لدعم روابط الصفحات الداخلية.

طريقة التحديث:
1. نزّل هذا الملف المضغوط وفك الضغط.
2. افتح مستودع GitHub الذي ينشر على mrsami01.github.io/discoverjo.
3. ارفع محتويات الملف المضغوط إلى جذر المستودع نفسه، بحيث يظهر index.html في الجذر وتكون مجلدات assets وimages وaudio بجانبه.
4. وافق على استبدال الملفات القديمة، وأضف 404.html و.nojekyll إذا لم يكونا موجودين.
5. انتظر حتى ينتهي النشر في GitHub Pages، ثم افتح https://mrsami01.github.io/discoverjo/ مع تحديث قوي للصفحة.

لا تضع الملفات داخل مجلد discoverjo داخل المستودع، لأن اسم المستودع نفسه يضيف هذا المسار عند النشر.
لا تفتح index.html مباشرة من الجهاز. افتح رابط GitHub Pages بعد اكتمال النشر.

هذه الحزمة مخصصة للرابط https://mrsami01.github.io/discoverjo/. عند تغيير اسم المستودع، يجب إعادة البناء بالمسار الجديد.
